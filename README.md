# SkyGuard Acoustic Drone Detection System

SkyGuard is an acoustic-based drone detection and monitoring system featuring real-time audio analysis, spatial radar display, spectral frequency processing, and active sensor management.

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Lucide Icons, Recharts, Vite
- **Backend**: Node.js, Express, TypeScript, Multer, Web Audio APIs

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
